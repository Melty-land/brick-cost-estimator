# 砖成本材料预算 · 成本估算系统

本地 Web 版砖类产品材料成本估算工具,依据《砖成本材料预算表_黑白打印版.xlsx》开发。
版式为 **A–L 12 列 Excel 化表格**;登录后默认进入「估算单」列表,点击任意批次即可打开其表格编辑。

**零第三方依赖 · 完全离线可用**:服务端仅用 Node.js 内置模块(含内置 SQLite `node:sqlite`),前端无框架、无 CDN、无外部字体。**不需要 npm install,不需要联网。**

---

## 一、环境需求

| 项目 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10/11(推荐);Linux / macOS 亦可 | 全部功能在 Windows 上开发与验证 |
| Node.js | **22.5 或更高(推荐安装 24 LTS 或更新)** | 服务端使用内置 `node:sqlite`(DatabaseSync);低于 22.5 会报 `Cannot find module 'node:sqlite'`。22.5–23.x 属实验 API 期,若启动异常请改用 24 LTS |
| 浏览器 | 微软 Edge / Chrome 等现代浏览器(推荐 Edge) | 纯本机访问,无需联网 |
| 磁盘 / 内存 | 任意普通办公电脑即可 | 数据库为本机单个文件,占用很小 |
| 网络 | **不需要**(安装 Node.js 时除外) | 运行全程离线 |

> 安装完成后整目录可**免安装拷贝/携带**(绿色版):复制到 U 盘或其它电脑解压即可运行,无需再装任何依赖。

## 二、首次安装(在其它电脑上)

### 第 1 步:安装 Node.js

1. 打开 <https://nodejs.org/zh-cn> ,下载 **LTS(长期支持)版**安装包(Windows 选 `.msi`);
2. 双击安装,一路"下一步"(保持默认勾选,安装程序会自动把 Node 加入 PATH);
3. 验证是否装好:打开**命令提示符(cmd)** 或 PowerShell,输入:

```
node -v
```

能显示版本号(如 `v24.x.x`)即成功。若提示"不是内部或外部命令",说明未加入 PATH——重启一次命令窗口,或重新运行安装包并勾选 "Add to PATH"。

### 第 2 步:拿到系统文件

把整个项目文件夹(本 README 所在目录,**含 `server.js`、`public/`、`启动.bat` 等文件**)复制到目标电脑的任意位置,例如 `D:\brick-cost\`(示例,可自行选择;中文路径亦可)。

> 方式不限:U 盘拷贝、局域网共享、或 `git clone` 本仓库。注意只需源码文件,程序运行时会自动创建自己的数据文件。

### 第 3 步:启动

**方式一(推荐,双击即可,仅 Windows)**

双击文件夹里的 **`启动.bat`**:

- 会自动在后台启动服务,并打开浏览器 `http://127.0.0.1:8237`;
- 会弹出「砖成本估算服务」黑色控制台窗口——**请保持它开启**,关闭它即停止服务;
- 若服务已在运行,再次双击只会重新打开浏览器,不会重复启动。

**方式二(命令行,跨平台通用)**

```
cd 系统文件夹路径      # 例如:cd D:\brick-cost
node server.js
```

看到 `请用浏览器打开: http://127.0.0.1:8237` 即启动成功,保持该窗口开启。

然后浏览器访问 <http://127.0.0.1:8237>。

### 第 4 步:登录

- 系统**首次启动会自动创建内置管理员账号 `admin`**(初始密码见下方说明),同时内置 11 种基础材料;产品配方、估算单等业务数据为空,按需新建即可。
- 登录页也可「注册」新账号:**除内置 admin 外的第一个注册账号自动成为管理员**,之后的注册为普通用户。

### 第 5 步:确认安装成功

登录后能看到「估算单 / 材料管理 / 产品配方 / 图表预览 / 历史对比」等标签页,即安装成功。

## 三、端口被占用怎么办(换端口)

默认端口 **8237**。若被占用(启动时提示 `端口 8237 已被占用`),换一个端口:

**命令行方式(Windows / Linux / macOS):**

```
set PORT=9000              # Windows(cmd)
# Linux / macOS 用:export PORT=9000
# PowerShell 用:$env:PORT = 9000
node server.js
# 然后浏览器访问 http://127.0.0.1:9000
```

> 换端口后,浏览器、导出链接等都跟随新端口;`启动.bat` 固定使用 8237,如需长期换端口可复制一份 bat 并修改其中端口号。

## 四、账号与安全

- 内置默认账号 `admin` 的初始密码为 **admin123**;
- **首次登录后请务必在「用户管理」→ 自己那一行「改密」中修改密码**;
- 管理员可新增用户、改角色、重置密码、停用/删除(不能删自己,系统至少保留一名启用管理员;停用账号立即踢下线);
- 登录会话有效期 7 天,过期需重新登录;登录状态保存在本机浏览器。
- **退出系统**:顶部右侧红色「退出系统」按钮(登录即可用)——点击后弹窗确认,确认即**停止本地服务**(需重新双击 `启动.bat` 才能再用)并尝试关闭本页;浏览器若拦截自动关页,手动关闭标签页即可。已编辑未保存的内容会自动存为本机草稿,下次可恢复。

> 界面登录页不再显示默认账号提示;默认口令以本文档为准。若忘记密码,由另一名管理员在「用户管理」中重置,或见下文"五、常见问题"。

## 五、常见问题(安装 / 启动排查)

| 现象 | 原因与处理 |
|---|---|
| 双击 启动.bat 后一闪而过,浏览器没打开 | 多半是 Node 未安装或未加入 PATH。先按"第 1 步"用 `node -v` 验证;或改用命令行方式 `node server.js` 直接看报错 |
| 提示 `Cannot find module 'node:sqlite'` | Node 版本低于 22.5。到 <https://nodejs.org> 安装 24 LTS 后重试 |
| 提示 `端口 8237 已被占用` | 见上文"三、换端口" |
| 浏览器能开但提示无法连接 | 服务窗口被关闭了;重新双击 启动.bat 或命令行启动 |
| 修改过文件但页面没变化 | 浏览器按 **Ctrl+F5** 强制刷新 |
| 忘了密码 | 用另一管理员账号在「用户管理」重置;若只有 admin 一个账号且忘记密码,可停服后删除 `data/brick.db` 再启动(会重建空库与默认账号,**业务数据会丢失**,慎用;平时请用"导出备份文件"定期备份) |
| 换了电脑,想把旧电脑的数据带过来 | 见下文"六、数据存储与迁移" |

## 六、数据存储与迁移

- **数据位置**:本机 SQLite 数据库 `data/brick.db`(该目录运行后自动创建,**不在 git 仓库中**);含材料、产品配方、估算单、用户、会话等表,事务写入、WAL 模式,崩溃不易损坏;
- **旧版兼容**:若旧版在 `data/data.json` 存过数据,首次启动新服务会自动迁移进 SQLite,原文件保留不动;
- **在线备份**:页面「数据备份」→「快照备份」一键生成一致性快照,存于 `data/backups/`,自动保留最近 30 份;
- **导出 / 导入**:「导出备份文件」下载单文件 `brick-data-日期.zip`,拷到另一台电脑后,在那台电脑登录 admin 用「导入恢复」即可还原(导入前自动快照,可回退);
- **整目录搬家**:停止服务 → 复制整个 `data/` 目录到新电脑同位置 → 启动,数据原样可用。

## 七、功能一览

- **登录 / 注册 / 用户管理**:全站需登录;开放注册(首个注册自动为管理员);admin 可管理用户(新增/改角色/重置密码/删除/停用;不能删自己、至少保留一名管理员;停用账号立即踢下线);
- **材料管理 / 产品配方 / 估算单 / 图表预览 / 历史对比** 五个标签页;
- **Excel 化表格编辑器**:单元格可编辑、公式栏支持 `=引用/SUM/IF/ROUND…` 自定义公式、自动重算、错误与循环检测;点击单元格高亮其公式影响链(引用来源/下游结果);
- **材料清单区(2026-09 修订)**:预算表材料清单区精简为 9 列 —— 序号 | 材料名称 | 上存材料(公斤) | 本期进料(公斤) | 库存材料(公斤) | 本期用料单价 | 本期用料数量(公斤) | 本期用料金額 | 占比(去掉不用的 单价/数量(公斤)/金额 三列),按原总宽加宽铺满,导出/打印同步;
- **上存/库存结转口径**:库存材料 = 上存 + 本期进料 − 本期用料数量(自动);打开同预算表编号的后续批次时,系统提示各材料上一批库存并支持「一键填入」为上存(逐批结转);
- **单位与规格**:单价按元/公斤录入、全表数量按**公斤**直乘不换算;材料吨价 = 金额合计÷用量合计**×1000**(元/吨,不 ÷1000);表格含**砖长/宽/高**规格行,自动计算砖面积/体积,并自动派生每平方/立方重量、每托重量、计划数与成品率;
- **保存体系**:估算单分「草稿 / 可用表格」;退出编辑时弹窗三选(存草稿 / 不保存 / 存为可用表格);编辑中**自动草稿**每 600ms 存入本机浏览器,误关/刷新可恢复,保存成功自动清除;
- **导出 Excel / PDF**:编辑预算表时一键导出 `.xls`(Excel 2003 兼容,版式同纸质表)或调起打印另存为 PDF(A4 横向、仅预算表),导出前自动提交公式栏输入;
- **退出系统**:顶部红色「退出系统」按钮,确认后停止本地服务并提示关闭页面(重新双击 启动.bat 恢复);
- **必填引导**:黄色高亮提示必填格(**含预算表编号**),填完自动取消;未填完必填项只能存为草稿;
- **相邻批次校验**:同**预算表编号**的相邻批次(日期、模数)不衔接时弹确认提醒;
- **编辑体验**:新建估算单**编制人自动填当前登录用户名**;表格版式固定,**1920 宽屏整表显示无需横向拖拽**(窄窗口自动出现横向滚动);
- **编号概念**:产品编号(产品档案,如 BZ-240)与估算单的预算表编号相互独立,导入产品配方时**不会**自动填入预算表编号;
- **成本总览**(位于估算单与图表预览之间):按 时间段/砖型(多选)/材料(多选,点哪项选哪项) 汇总生产总成本、平均成本/砖型、材料总消耗;「生成图表」按同一筛选在新窗口打开图表预览;
- **图表预览(跨批次+口径)**:材料成本构成环形图 / 批次成本对比(单柱) / 各批次每平方成本折线 / 各材料库存条形,**全局"金额/用量"口径切换**,按需懒加载;顶部与成本总览共用筛选并可互相跳转;仅对比两图可点击跳批次;
- **存储与备份**:数据存于本地 SQLite;支持在线快照(VACUUM INTO,保留 30 份)、一键导出单文件 zip、导入恢复(需管理员,导入前自动快照)。

## 八、目录结构

```
成本估算系统/
├─ server.js            # 服务端(唯一入口,Node 内置模块;含 SQLite 与备份/导入导出 API)
├─ 启动.bat             # Windows 一键启动(自动开服务 + 开浏览器)

│  └─ js/               #   app/store/calc/formula/sheet/charts/exporter
├─ data/                # 运行后自动生成: brick.db(SQLite)、backups/(快照)、data.json(旧版兼容)
├─ test/                # 零依赖测试(单元 + API + 无头浏览器 CDP)
├─ README.md            # 本文件(安装/使用/部署)
└─ 使用说明.md           # 详细操作手册(材料/配方/估算单/计算规则)
```
